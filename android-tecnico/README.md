# ROVAN Técnico em Campo para Android

APK compatível com Android 7.0 ou superior. Inclui acesso à câmera, seleção de arquivos, GPS, backup JSON e impressão/salvamento do relatório em PDF.

- Pacote: `br.com.rovan.campo`
- Site carregado: `https://jrovan2017.github.io/campo/`
- Dados operacionais permanecem no armazenamento do aplicativo/WebView do aparelho.
