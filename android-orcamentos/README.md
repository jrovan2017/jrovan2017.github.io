# ROVAN Orçamentos para Android

Aplicativo Android compatível com Android 7.0 ou superior, criado para aparelhos antigos como o Motorola Moto G5.

- Pacote: `br.com.rovan.orcamentos`
- Site carregado: `https://jrovan2017.github.io/orcamentos/`
- Backups JSON são gravados na pasta Downloads.
- A proposta pode ser impressa ou salva como PDF pelo serviço de impressão do Android.
- O APK de depuração é assinado automaticamente pelo Android Gradle Plugin e pode ser instalado fora da Play Store.
